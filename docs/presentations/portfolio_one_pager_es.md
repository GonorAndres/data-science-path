# Portafolio en Una Pagina (Espanol)

**Andres Gonzalez Ortega** | Actuario UNAM | CDMX, Mexico

## En una oracion

Cientifico de datos con formacion actuarial UNAM y un portafolio que cubre NLP, computer vision, forecasting, recomendadores, ML causal y MLOps, con teoria tecnica y despliegues en produccion.

## Dos tracks

- **Ciencia de Datos Pura.** 11 proyectos sobre datasets publicos no-insurance. NLP, CV, series de tiempo, recomendadores, ML causal, MLOps, LLMs. [`projects/00_pure_ds_index.md`](../../projects/00_pure_ds_index.md).
- **Actuarial / Seguros.** 1 proyecto completo (tarificacion con GLM y GBM, SHAP, analisis de fairness) y 6 scaffolds. Especializacion de dominio poco comun en candidatos DS.

## Lo que un recruiter puede abrir

- `projects/mlops-model-service/`: FastAPI + Docker + Cloud Run + GitHub Actions.
- `projects/nlp-reviews-multilingual/`: DistilBERT multilingue sobre Amazon Reviews Multi.
- `projects/timeseries-retail-forecast/`: LightGBM jerarquico sobre M5.
- `projects/recsys-movielens/`: recomendador two-tower con baseline ALS.
- `docs/theory/`: libreria teorica de 15 ensayos.
- `career/`: CV bilingue, copy LinkedIn, preparacion para entrevistas.
